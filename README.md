# Retail Sales & Profit Dashboard

Excel dashboard project for reviewing retail sales and profit information.

## Repository Contents

- `retail_sales_&_profit_dashboard.xlsx` — the project workbook/report.
- `dashboard image.png` — a visual preview.

## Getting Started

1. Download or clone this repository.
2. Open the workbook in Excel or a compatible spreadsheet application. Review the sheets, KPI calculations, tables, charts, and filters before relying on results.

The project provides a dashboard-oriented way to review the data in the included file. Exact metrics, reporting periods, data definitions, and business conclusions should be verified from the workbook/report itself rather than inferred from the repository name.
